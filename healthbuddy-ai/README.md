# HealthBuddy AI

HealthBuddy AI is a safe wellness web app that turns everyday routines into daily health missions, routine insights, habit tracking, streaks, and community wellness challenge ideas.

## How to View the Project

### 1. Best Option: Open the Live Website

Use the live website link from the project submission first. This works directly in the browser and does not require installing anything.

### 2. Backup Option for Windows: Use the VBS Launcher

If the live website link is unavailable, download and extract the ZIP first. Then double-click:

```text
RUN_HEALTHBUDDY_WINDOWS.vbs
```

This opens the website locally with a cleaner no-terminal launch.

### 3. Final Backup Option: Use the CMD Launcher

If the VBS launcher does not work, double-click:

```text
RUN_HEALTHBUDDY_WINDOWS.cmd
```

A command window may appear while the local server is running.

## Streak Rule

The streak updates only when the user clicks **Finish Day & Update Streak**.

- If all habits are completed, streak increases by 1.
- If even one habit is incomplete, streak resets to 0.
- Clicking habits repeatedly does not increase streak.
- The streak is saved in local storage.

## Safety Note

HealthBuddy AI is not a medical diagnosis tool. It does not prescribe medicine, recommend extreme diets, or replace doctors. It focuses on safe daily wellness habits. For serious concerns, users should talk to a doctor, caregiver, counselor, coach, parent, or trusted adult.
